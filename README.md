# Intelligence Investigation Board (Concord IIB)

A modern, highly-interactive web application for mapping intelligence, analyzing evidence, and managing investigation workflows. 

## 🚀 Features

- **Interactive Evidence Board**: Visual drag-and-drop cards for suspects, documents, and physical evidence.
- **Kanban Task Management**: Manage investigation states across Backlog, In Progress, Review, and Completed stages.
- **Relationship Node Graph**: Interactive physics-based visualization showing connections between entities.
- **Real-time Global Search**: Instantly filter across all evidence and tasks.
- **Hardware-Accelerated UI**: Highly optimized rendering for 60fps animations and seamless drag-and-drop operations.

## 🛠️ Tech Stack

- **HTML5** & **Vanilla JavaScript** (No heavy frameworks)
- **Vanilla CSS** with modern Grid/Flexbox layouts
- **D3.js-style physics simulations** written in pure JS

## ⚡ Setup & Deployment

### Local Development
To run this project locally:
1. Clone the repository.
2. Open `index.html` in your browser, or run a local server:
   ```bash
   npx serve -p 3000
   ```

### Live Deployment
This project is configured to be deployed easily via **GitHub Pages**.

1. Go to the repository **Settings** > **Pages**.
2. Select the `main` branch.
3. Click **Save**.

The site will be live at `https://yourusername.github.io/frontend-war/`.
